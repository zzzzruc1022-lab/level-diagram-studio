# 关卡简图工坊 1.1

本次为 1.1.0 的维护更新，版本号和下载地址不变。网页版的教学图片改为按需加载，减少首次打开时的下载量；Windows 版同步更新，离线教程完整保留。已有工程可继续使用。

1. 比例尺与公制单位：用米、厘米设置尺寸，网格间距和吸附步长可调整，旧工程的位置和大小比例保持不变。
2. 地图尺寸与边界：自定义地图范围，支持512×512米等尺寸，可选择越界提醒或限制放置。
3. 圆弧与等厚弯墙：拖动边中点制作内凹、外凸圆弧，墙壁可以弯曲，也能转回直墙。
4. 跨边缘开洞：空洞可以切到平面或墙壁边缘，用来制作缺口、门洞，并支持移动、缩放和旋转。
5. 图片组件与底图：导入已有平面图，在上面画路线、加文字和标记，支持移动、缩放、旋转及裁切。
6. 图例与地图信息：从已有组件中添加图例，自定义名称和背景，比例尺、指北针也能选择加入导出图稿。
7. 三种布局与三种配色：悬浮面板、独立工具列、顶部工具带自由切换，下次打开会保留设置。
8. 路线遮挡与三维编辑：路线可以被墙壁、屋顶遮挡，也能用三色坐标轴调整整条路线或单个节点。
9. 重叠组件选择：右键直接查看重叠组件，指向名称预览高亮，也可以用Alt单击轮选，更方便选中被墙挡住的楼梯。
