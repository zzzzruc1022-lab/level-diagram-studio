## 修复与整理

- 旧源码打包脚本只枚举 src 第一层，漏掉帮助媒体和部分回归测试，并可能把目录当作文件校验。改用明确公开目录的递归白名单，包含7段GIF、当前测试、许可证和锁文件；排除暂存、QA日志、私有工程及依赖目录，归档逐文件校验。干净安装检查另外发现吸附测试依赖QA中的旧版求解器；已将这个必要对照样本移入tests/fixtures，让公开包可独立运行回归。
- 自动对比色图像原来只限制宽度，极窄窗口或很高的SVG可能生成超大Canvas。现限制长边4096、总像素16777216，保持比例；导出画布和图稿尺寸不变。不将局部优化表述为所有设备的性能保证。
- PNG图像载入和Blob生成后再次核对当前预览，关闭或切换预览后不下载旧图稿；取消均释放临时对象网址。
- 桌面F1菜单打开完整内置帮助，便携EXE不依赖外部说明路径。外部教程由与内置帮助相同的内容生成，HTML包含7段离线GIF，按需播放、离屏停止。
- 新增单文件Windows x64便携EXE，保留完整目录ZIP、单HTML、示例及源码ZIP。GitHub源码与大体积Release附件分开，附Pages和Windows构建工作流、SHA256校验。
