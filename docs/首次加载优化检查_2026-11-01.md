# 首次加载检查与本地优化

范围：1.1 发布后的本地优化，未推送 GitHub、未部署公开网站、未重打或更新 EXE。后台独立浏览器检查，不操作用户正在使用的窗口。

## 测量与判断

检查构建入口和全部模块的打包关系，并重点审视启动、视图刷新、几何/路线缓存、图片资源、暂存、导出及帮助加载。首页 3,031,328 字节，其中帮助区域 2,527,847 字节，占约 83.4%。压缩后的程序代码约 392 KB，已经使用 Terser，未引入网页运行时框架或远程字体。首开下载包含全部七段 GIF，使用说明是否打开不影响下载量。

在独立 Chrome 中模拟 1.6 Mbps 下行、150 ms 延迟，使用 gzip，关闭缓存，每个样本新建浏览器配置，优化前后各三次。统计编辑器 API 就绪时间，含页面下载、解析和启动，不等同于用户主观验收：

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 网页 HTML | 3,031,328 B | 525,588 B |
| gzip 下载量（本地同一压缩设置） | 1,993,132 B | 165,863 B |
| 冷启动三次 | 10,300 / 10,269 / 10,255 ms | 1,064 / 1,049 / 1,056 ms |
| 冷启动中位数 | 10,269 ms | 1,056 ms |

首页体积减少约 82.7%，压缩传输量减少约 91.7%。上述时间为受控本地对照，不是优化后线上实测。公开 GitHub Pages 的一次访问超过30秒，后一次约6.3秒且命中缓存，不适合作为冷启动对照；响应确认使用 gzip，压缩体积约2 MB。连接与网络波动仍会影响实际访问。

基线 CPU 采样和导航时间显示，这组空项目首次进入主要等待下载，接收完成到编辑器就绪约60–70 ms。已有几何缓存、路线遮挡缓存、拖动逐帧合并、暂存防抖和导出栅格上限继续保留。复杂三维布尔计算与大工程导入不是此次测量证明的首页瓶颈；没有为减少源码行数重写这些逻辑或移除兼容分支。

## 实现

- 同一次构建产生 `dist/index.html`（完整离线文件）及 `dist/web/`（网站）。绘图程序、CSS、工程种子、公告和帮助正文完全一致。
- 网站教学媒体改为同站点文件；文件名包含内容摘要，可独立缓存。图片在说明区域出现时加载，GIF 在点击演示后加载。没有新增包依赖或第三方资源服务。
- 停止演示只处理正在播放的项，避免重设所有封面的地址。慢网显示加载提示，失败可以重试；关闭说明和离开当前演示范围仍停止播放。
- 离线文件继续嵌入原始七段 GIF 和全部封面，不依赖网络；离线内容安全策略保持不变。网站只额外允许同源图片。
- Pages 工作流在本地改为部署整个 `dist/web/`。尚未推送，公开地址与安装包未改。后续发布时必须带上 assets，不能只上传网站 HTML。
- 原暂存键、数据版本、坐标与尺寸、几何渲染、导出算法、布局和配色均未更改。

## 本轮验证

1. 自动回归：原28个脚本及新增 `verify-web-build.cjs` 均通过。新检查核对14个媒体文件与源码字节一致、内容摘要正确、压缩体积上限，以及在线/离线还原媒体地址后整份HTML完全相等。
2. 实际后台浏览器操作：首开没有请求教学媒体；七段演示均能加载/播放/停止；慢网取消与失败重试通过；离线单文件七段演示全部可用且零HTTP请求。
3. 旧工程经文件选择导入、下载JSON、刷新重开，组件数据不变；含两张图片的便携工程在全新配置中重开，并实际下载和解码PNG/SVG。
4. 穿洞与屋顶遮挡工程：三种布局×三种视图的9组截图逐字节相同，生成SVG文本也完全相同。三种配色可切换。
5. 25组件复合建筑（导入已有检查工程，非本轮手工搭建）：平面/立面/立体3组截图和SVG与基线完全相同，立体含232个面。小样本渲染耗时只作为回归观察，不宣称几何计算有提速。
6. 12组实际重叠选择回归通过，包含墙两侧少量突出、踏步间隙、三布局、小窗口、45个楼梯长菜单、键盘/滚动、保存重开和PNG/SVG下载解码。
7. 与已发布源码ZIP比较：没有缺失文件；22个教学素材、fixtures、锁文件及许可证受保护项保持一致。修改集中在构建、帮助加载、发布路径及相关检查和说明。

证据在 `qa/loading-2026-11-01/`：`comparison.json`、`before-report.json`、CPU采样、`regression.log`、`ui-report.json`、`complex-report.json`、`overlap/browser-report.json`、截图及下载文件。自动检查、实际浏览器操作与用户验收分别记录。本轮未运行真实EXE验收。

本地试用：运行 `node tools/serve-web.mjs`，访问 http://127.0.0.1:10436/ 。此端口与10435的浏览器暂存独立；要试自己的原工程，请先在原页下载工程JSON，再到优化预览中打开。原页暂存不会被覆盖。
